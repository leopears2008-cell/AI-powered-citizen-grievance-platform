# Civic operations UI and integration notes

## UI added
- Clickable SVG district explorer with 38 districts, threshold colours and sample SLA metrics.
- Printable sample CM Cell/Secretariat receipt with QR code and browser Print/Save as PDF.
- In-app notification drawer with simulated Submitted, Officer Assigned, Field Inspection and Resolved events.
- Monsoon/disaster response toggle and 2-hour critical target message.
- Font resizing, contrast toggle and Tamil/English browser speech synthesis.

## Important limits
SLA rates and petition counts are demonstration data, not live operational data. SVG points are schematic and are not official district boundaries. Collector/ministry contacts are intentionally not fabricated; populate protected district_sla_snapshots from a verified official directory and retain source links/verification dates.

The receipt is a sample, not an official government receipt. It does not copy the government emblem. The QR image is generated by a remote QR service and encodes a sample query URL. Production needs a stable public tracking route and an unguessable token; the public endpoint must return minimal status data only.

Emergency toggle in the current UI is local-only. Operational mode needs authenticated admin API routes, audit logging, server-side SLA calculation, and an actual persisted setting. Live WhatsApp/SMS needs provider configuration, citizen consent/opt-out, signature-verified webhooks, idempotency and delivery logs. The timeline drawer is a simulation, not evidence of messages sent.

The migration adds protected snapshot/event tables and emergency setting columns. Apply via the existing Supabase migration process after backup and review. Accessibility features are a starting point, not a certification of GIGW compliance; conduct keyboard, focus, screen-reader and contrast testing.
